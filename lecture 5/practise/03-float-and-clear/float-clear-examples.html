Float Values Summary:
  • float: left - Element floats to the left
  • float: right - Element floats to the right
  • float: none - Default value, no floating
  • float: inherit - Inherits from parent element
Clear Values Summary:
  • clear: left - No floating elements on the left side
  • clear: right - No floating elements on the right side
  • clear: both - No floating elements on either side
  • clear: none - Default value, allows floating elements on both sides
