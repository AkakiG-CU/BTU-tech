CSS Position Property Examples

Static: Default positioning. Elements flow normally, top/left/right/bottom have no effect.
Static
Relative: Positioned relative to its normal position. Other elements are not affected.
Relative
Absolute: Positioned relative to the nearest positioned ancestor (or viewport if none).
Absolute
Fixed: Positioned relative to the viewport. Stays in place when scrolling.
Fixed
Sticky: Switches between relative and fixed based on scroll position.
Sticky
