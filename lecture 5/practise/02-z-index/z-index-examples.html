Z-Index Property Examples

Natural Stacking Order: Without z-index, elements stack in the order they appear in HTML (later elements on top).
Red
First
Blue
Second
Green
Third
With Z-Index: Higher z-index values appear on top, regardless of HTML order.
Red
z-index: 3
Blue
z-index: 1
Green
z-index: 2
Negative Z-Index: Elements with negative z-index go behind their parent.
Behind
z-index: -1
Front
z-index: 1
Z-Index Range: Values can range from negative infinity to positive infinity.
1000
10
1
-10
Important Notes:
  • Z-index only works on positioned elements (position: relative, absolute, fixed, sticky)
  • Elements with higher z-index values appear on top
  • If z-index values are equal, natural stacking order applies
  • Z-index creates stacking contexts
