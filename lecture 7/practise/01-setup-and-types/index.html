Setup & Types

Install and Compile

  1. Install: npm install -g sass
  2. Compile once: sass style.scss style.css
  3. Watch mode: sass style.scss style.css --watch

Source maps (.map) help DevTools map CSS back to SCSS.

SCSS vs Sass (indented)

SCSS

$primary: #3498db;
button {
  background: $primary;
  color: #fff;
}

Sass (indented)

$primary: #3498db
button
  background: $primary
  color: #fff
