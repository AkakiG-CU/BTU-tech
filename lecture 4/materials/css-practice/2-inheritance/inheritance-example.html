CSS Inheritance Demonstration

This text inherits the font-family (Georgia), color (darkblue), font-size (18px), and line-height (1.6) from the body element.

Parent Container

This paragraph is inside a parent div. It inherits text properties from the body.

Child Element

This paragraph inherits all text properties from its ancestors (body → parent-div → child-element).

This paragraph overrides the inherited color with red, but still inherits other properties like font-family and font-size.

This div has its own margin, padding, border, and width. These properties are NOT inherited by child elements.

Inherited Properties Examples

  • Font properties: font-family, font-size, font-weight, font-style
  • Text properties: color, text-align, line-height, letter-spacing
  • List properties: list-style-type, list-style-position
  • Other: visibility, white-space, word-spacing

Non-Inherited Properties Examples

  • Box model: margin, padding, border, width, height
  • Background: background-color, background-image
  • Layout: display, position, float, z-index
  • Effects: box-shadow, opacity, transform
