DOM Display Types Demonstration

Block Elements (display: block)

Block elements:

  • Take up the full width available
  • Start on a new line
  • Can have width, height, margin, and padding
  • Stack vertically
Natural block element: DIV

Inline Elements (display: inline)

Inline elements:

  • Only take up as much width as needed
  • Do not start on a new line
  • Cannot have width or height set
  • Vertical margins are ignored

This paragraph contains natural inline elements: link, span, strong, code, and em.

Inline-Block Elements (display: inline-block)

Inline-block elements:

  • Flow like inline elements (side by side)
  • Can have width, height, margins, and padding like block elements
  • Perfect for creating layouts with equal-sized boxes

Common HTML Elements by Display Type

Natural Block Elements:

  • div - Generic container
  • p - Paragraph
  • h1-h6 - Headings
  • ul, ol, li - Lists and list items
  • header, footer, section, article - Semantic elements

Natural Inline Elements:

  • span - Generic inline container
  • a - Links
  • strong, em - Text emphasis
  • img - Images (inline-block by default)
  • code - Code snippets
