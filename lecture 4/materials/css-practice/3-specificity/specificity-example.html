CSS Specificity Demonstration

Understanding Specificity Values

Specificity is calculated as: (inline-styles, IDs, classes, elements)

  • Inline styles: 1,0,0,0
  • IDs: 0,1,0,0
  • Classes, attributes, pseudo-classes: 0,0,1,0
  • Elements and pseudo-elements: 0,0,0,1

Specificity Examples

1. This paragraph uses element selector (p) - Specificity: 0,0,0,1

2. This paragraph has class "highlight" - Specificity: 0,0,1,0 (wins over element)

3. This paragraph has ID "special" - Specificity: 0,1,0,0 (wins over class)

4. This paragraph has multiple classes - Specificity: 0,0,2,0

5. This paragraph has ID + class - Specificity: 0,1,1,0

6. This paragraph matches a very specific selector - Specificity: 0,1,2,2

7. This paragraph uses !important - Overrides high specificity

8. This paragraph uses inline styles - Specificity: 1,0,0,0 (highest specificity)

Specificity Rules

  1. Importance: !important declarations override normal declarations
  2. Specificity: Higher specificity values win
  3. Source Order: When specificity is equal, the last rule wins
