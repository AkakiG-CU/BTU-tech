CSS Box Model Demonstration

The CSS Box Model

Every HTML element is essentially a rectangular box consisting of four areas:

  1. Content: The actual content (text, images, etc.)
  2. Padding: Space between content and border
  3. Border: The border around the padding
  4. Margin: Space outside the border

Box-sizing: content-box vs border-box

content-box (default)

Width and height apply to the content area only. Padding and border are added to the total size.

content-box
Width: 200px
Total: 250px
(200 + 40 + 10)

border-box

Width and height include content, padding, and border. More predictable sizing.

border-box
Width: 200px
Total: 200px
(includes all)

Margin Examples

Margin creates space outside the element's border:

margin: 20px
All sides: 20px
margin: 10px 30px
V: 10px, H: 30px
margin: 5px 25px 15px
T: 5px, H: 25px, B: 15px
margin: 5px 10px 15px 20px
T: 5px, R: 10px, B: 15px, L: 20px

Padding Examples

Padding creates space inside the element, between content and border:

padding: 20px
All sides
padding: 10px 30px
Vertical | Horizontal
padding: 5px 10px 15px 20px
Top | Right | Bottom | Left

Border Examples

Borders can have different styles, widths, and colors:

border: 3px solid red
border: 3px dashed blue
border: 3px dotted green
Mixed borders
Different on each side

Shorthand Property Patterns

One Value

margin: 10px; → All four sides get 10px

Two Values

margin: 10px 20px; → Vertical: 10px, Horizontal: 20px

Three Values

margin: 10px 20px 15px; → Top: 10px, Horizontal: 20px, Bottom: 15px

Four Values

margin: 10px 20px 15px 5px; → Top: 10px, Right: 20px, Bottom: 15px, Left: 5px

Remember: Think of a clock - starts at 12 (top) and goes clockwise!
